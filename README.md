# Ayşişim için atama uygulaması 🦷

2026-3 açıktan atama listesindeki **diş tabibi** kadrolarını keşfetmek ve 10 tercihlik listeyi oluşturmak için küçük bir React + Vite uygulaması.

🌐 **Canlı:** https://memreeozdemir.github.io/aysisim-atama/

```bash
npm install
npm run dev
```

Veri `src/data/kadrolar.json` dosyasında; Excel güncellenirse `python3 scripts/convert.py` ile yeniden üretilir. `main` dalına her push GitHub Actions ile GitHub Pages'e yayınlanır.
